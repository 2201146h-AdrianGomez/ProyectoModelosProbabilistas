
A. Validaciones
  ✓ una red de 3 nodos con CPT uniformes es válida
  ✓ menos de 3 nodos no es válida
  ✓ no se pueden agregar más de 10 nodos
  ✓ nombres repetidos se rechazan (sin importar mayúsculas)
  ✓ se rechazan ciclos A→B→C→A
  ✓ un nodo no puede ser su propio padre
  ✓ un ciclo en un archivo se detecta al validar
  ✓ una fila de la CPT que no suma 1 se reporta con su descripción
  ✓ probabilidades fuera de [0,1] o NaN se rechazan
  ✓ CPT con el número de filas equivocado se rechaza
  ✓ cambiar los estados de un padre reinicia la CPT del hijo con el tamaño correcto
  ✓ eliminar un nodo limpia las referencias de sus hijos
  ✓ renombrar un nodo actualiza a sus hijos

B. Eliminación de variables vs. cálculos hechos a mano
  ✓ Pasto mojado: P(Lluvia=Sí | Pasto=Sí) = 0.16038 / 0.44838 ≈ 0.357687
  ✓ Alarma: P(Robo=Sí | Juan=Sí, María=Sí) ≈ 0.284 (valor clásico de Russell & Norvig)
  ✓ Sin evidencia, la marginal de una raíz es su propia distribución a priori
  ✓ La distribución resultante suma 1
  ✓ Evidencia imposible (probabilidad 0) produce un error claro
  ✓ Una variable no puede estar en la consulta y en la evidencia
  ✓ El orden de eliminación manual se respeta y no cambia el resultado
  ✓ Un orden manual incompleto se rechaza
